# FrameTrace Korean Preview/Window ULW Notepad

## Bootstrap

- Skills used:
  - `omo:ulw-loop`: durable goal, criteria evidence, cleanup, checkpoint.
  - `omo:frontend`: existing web UI/UX change; loaded project `DESIGN.md`, design router, redesign skill, and perfection checklist.
  - `omo:visual-qa`: required after UI work; use real browser evidence via agbrowse where possible.
- Tier: LIGHT.
- Justification: scoped to existing vanilla static `gui/evidence-viewer` UI copy and interaction; no Rust engine, auth, persistence, external integration, DB, or cross-domain refactor.
- User intent: Korean-first forensic UI, make previewing video/recovered evidence easier, consider a window-like mode without adding hype.

## Scenario Plan

- C001 Korean-first first screen: browser at 1280 must show Korean operational labels plus conservative forensic terms.
- C002 Preview/window flow: browser at 375/768/1280 must open a candidate preview and a window-like inspection surface with report/export/status reachable and no horizontal overflow.
- C003 Regression: JS syntax/static assertions/cargo lib tests pass; browser/server cleanup recorded.
