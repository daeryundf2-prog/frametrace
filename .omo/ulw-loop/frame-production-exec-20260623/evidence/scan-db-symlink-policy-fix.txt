Implementation summary
- src/case_db/core.rs:
  - open_case_db now creates the case root if needed, validates db/case.db with require_case_output_path, then creates the db directory and opens SQLite.

- src/scan.rs:
  - write_scan_outputs uses write_case_text for db/scan_runs, db/video_index.json, db/videos.jsonl, and db/video_paths.tsv.
  - write_case_text applies require_case_output_path before write_text.
- tests/cli_output_policy.rs:
  - Adds scan-folder case/db symlink regression and asserts no outside case.db, video_index.json, videos.jsonl, video_paths.tsv, or scan_runs are created.
