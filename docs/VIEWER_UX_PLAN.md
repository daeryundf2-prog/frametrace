# Viewer UX Plan — 크기, 창모드, 대량 선별

Status: implemented (viewer assets embedded from assets/, batch CLI shipped; gui/evidence-viewer prototype sync pending)
Scope: `review/evidence-viewer.html` (generated by `src/html_report.rs`, real case data) and, in a later pass, the same patterns for the `gui/evidence-viewer/` prototype.
Hard constraints: the review page must stay **serverless** (open directly from `file://` on a field workstation, no server, no fetch). All reviewer state therefore lives in `localStorage` plus downloadable JSON files, never in a backend.

## Phase 1 — 뷰어 크기: 가변 레이아웃

Problem today: `min-width: 1180px` forces horizontal scroll on laptops; the three columns are hard-coded `320px / 1fr / 300px`; the record list height is a fixed `calc(100vh - 278px)`.

1. Remove the fixed `min-width`; add responsive breakpoints:
   - < 1280px: inspector column collapses into a toggle drawer.
   - < 960px: single-column stacking (list on top, viewer below).
2. Draggable splitter between the three columns (pointer events, `grid-template-columns` updated live; double-click a splitter resets to default).
3. Video stage size modes: `fit`(기본) / `50%` / `100%` / `200%`, plus a zoom slider; `object-fit: contain` kept so nothing crops.
4. Persist all layout state (column widths, drawer state, video zoom, selected size mode) in `localStorage` under a per-case key (`ft.viewer.<case_id>.layout`) and restore on load.

Acceptance: 1366×768 laptop shows the full workflow without horizontal scroll; a dragged layout survives reload.

## Phase 2 — 창모드: 재생 공간 전환

1. **전체화면(Fullscreen)**: viewer stage Fullscreen API 토글 (`f` 키, 우상단 버튼). 종료는 `Esc`.
2. **시어터 모드**: list/inspector 숨기고 영상 스테이지가 남은 폭 전부 차지 (`t` 키). 상태는 layout과 함께 저장.
3. **PiP(Picture-in-Picture)**: 브라우저 PiP API 버튼 — 다른 창 위 항상 표시 재생 (포렌식 리뷰 중 다른 문서 대조용).
4. 창모드 진입 시 현재 재생 시간 유지; 모든 모드에서 `dl` 인스펙터 값은 그대로 접근 가능해야 한다(시어터에서는 Drawer로).

Acceptance: 세 모드가 키보드만으로 전환되고, 새로고침 후 마지막 모드가 복원되며, file:// 환경에서 동작한다.

## Phase 3 — 대량 선별: 멀티셀렉트 + 벌크 동작

Problem today: single-select only (`activeId`), 100-row fixed pagination, no marking workflow.

1. **선택 모델**: 각 행에 체크박스 + `selectedIds: Set` (video/carved/filesystem 공통). 클릭=미리보기(기존), 체크박스=선택, `shift+click`=범위 선택, `ctrl+a`=필터 결과 전체 선택(페이지 경계 포함), `ctrl+d`=선택 해제, `space`=현재 행 토글.
2. **선택 요약 바**: 하단 고정 바 `N개 선택 · 전체선택/해제 · 복사(ID/경로) · 목록 다운로드`.
3. **판독 상태 태깅**: `reviewed / important / needs_verification` 벌크 토글. `localStorage` 키 `ft.viewer.<case_id>.marks`에 저장, 행 배지로 표시, 메트릭 카드(판독됨/중요/검증대기)에 반영.
4. **페이지네이션 강화**: 페이지 크기 100/250/500/1000 선택, "N–M / 전체" 표시, 필터 결과 전체 건수 유지. 10k+ 레코드에서도 필터가 프레임 드랍 없도록 검색어 디바운스(150ms) + 정렬된 인덱스 재사용.
5. **검색 하이라이트**와 필터 프리셋(예: `validation-failed`, `candidate-unvalidated` 원클릭 칩).
6. **키보드 도움말** (`?`): 단축키 치트시트 모달.

Acceptance: 5,000 레코드 케이스에서 필터→전체선택→상태 태깅이 마우스/키보드만으로 수행되고, 새로고침 후 선택·마크가 유지된다.

## Phase 4 — 선택을 엔진으로: 셀렉션 파일 + 배치 CLI

브라우저(정적 페이지)는 파일을 쓸 수 없으므로, 선택 결과를 **버전 있는 JSON 파일**로 내려받아 CLI가 소비하는 연결선을 만든다.

1. **셀렉션 파일 스키마** (`selection.schema_version: 1`): `{ case_id, created_unix, items: [{ selector, kind, action: "export"|"proxy"|"thumbnail"|"validate", format, time_seconds?, notes }] }`. 뷰어의 "목록 다운로드" 버튼과 "올리기" 파일 입력으로 왕복 가능.
2. **`frametrace export-batch <case> --selection <file>`**: 항목별로 기존 `video_export`/`artifacts` 경로 재사용, `--dry-run` 지원, 실패 항목은 건너뛰고 요약. 배치 전체는 하나의 job으로 기록하고 결과를 `artifacts/logs/batch-log.jsonl`(체인 감사)에 남긴다.
3. **`frametrace validate-batch <case> --selection <file>`**: `validate_artifact` 반복, 검증 로그는 기존 validation-log 체인에 그대로 적재.
4. **`frametrace import-marks <case> marks.json`**: 브라우저 판독 마크를 SQLite `review_marks` 테이블(case_db schema v3, 기존 v1→v2 백업 마이그레이션 패턴 준수)로 흡수 — 검관자의 판독 결정이 DB로 방어 가능하게 남는다.
5. **`frametrace export-marks <case>`**: DB 마크를 JSON으로 역방향 내보내기(브라우저 올리기용).

Acceptance: 뷰어에서 선택 → 다운로드 → `export-batch --dry-run` → 실행 → `package-case`에 파생물 포함까지 E2E. cli_smoke에 배치 dry-run 케이스 추가.

## Phase 5 — 문서·테스트·정리

- `docs/EVIDENCE_VIEWER_GUI.md` 갱신(새 UX 계약), README의 뷰어 설명 업데이트.
- Rust: 셀렉션/마크 파일 파싱 단위 테스트, 배치 dry-run 테스트, render 스냅샷 테스트에 새 UI 마커 추가.
- JS는 기존 CI(`node --check`) 유지 + 수동 QA 체크리스트를 본 문서에 기록.
- 게이트: `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, `cargo test --locked`.
